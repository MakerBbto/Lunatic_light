# Lunatic_light
An intelligent lamp shaped like our natural satelite, the Moon. This project was created for the exposition [ArteFab](https://textile-academy.org/artefab-2024/) in Puebla, México, during the [Fab24 conference](https://fab24.fabevent.org/), and upgraded as stated on this document.

## How does it work?
The first setting of the lamp requests the current phase of the moon from the [Wttr.in](https://wttr.in/) online weather service, and then translates it to the neopixel array surrounding the sculpture, to show this information. The second setting allows you to pick which phase of the moon is to be shown. The third setting is for changing the brightness of the shown phase. The fourth setting is for the colour, starting on white, then orange (as in the moonrise) and finally red, as in a blood moon eclipse. All of this changes are done with a regular rotary encoder with a switch.
